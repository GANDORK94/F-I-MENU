This is a custom interactive F&I menu that can be used to present to customers in finance office goiing over terms and pricing of F&I products (GAP insurance & Extended Warranty)
In this menu, the user can hot swap different values including Vehicle price, APR, F&I product pricing. In addition there are different terms options. 
Once a option is selected there is a PDF printable option as well.
There are also instructions on how to make this IPAD compatible.
